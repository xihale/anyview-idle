# anyview-idle

AnyView 刷课工具（fuckView 的运行时后继）：Go 单二进制 + 内嵌 Vue 3 / Element Plus 前端。

两种任务模式：

- **挂机计时（idle）**——逐题为未通过的题累积 accumTime（exam WS 401 计时消息对），
  可选注入仿人错误尝试（编译错/运行错，数量可控）。
- **自动刷题（solve）**——oracle 泄露两轮法自动过题（ fuckView analysis/09 附 2 实测可行）：
  交模板空桩跑一轮判题，判题回显会逐组泄露「输入 + 正确结果」；据此生成查表硬编码代码
  （constructor 截留 stdin、整块输入归一化查表、命中即打印正确输出）再交判，`passed=true`
  即落 pass。每题存档快照、判后原样还原读回核对。

多账号：每个浏览器一条 cookie 对应一个独立会话，各自登录、各自刷课、状态互不可见；
所有账号的上游请求共享 `-rpm` 全局限速（同一出口 IP 防 WAF 拉黑）。
任务结束自动下线让位；token 失效默认 3 小时后自动重登续跑（用户优先）。

协议细节见 fuckView 仓库 `analysis/`（02 登录 / 04 模板 / 06 gdb / 09 WAF+泄露 / 10 计时）。

## 用法

```bash
make build                     # 前端 (bun + vite) + go build, 产物 ./anyview-idle
./anyview-idle                 # 默认 http://127.0.0.1:8765
./anyview-idle -addr :9000     # 自定义监听
./anyview-idle -rpm 20         # 全局上游限速 (每分钟请求数, 所有账号共享, 默认 20)
make dev                       # 前端热更开发 (vite :5173, /api 代理 :8765; 后端另起 go run .)
make test                      # go test ./... (含本地 gcc 编译并运行查表代码的行为单测)
```

浏览器打开后：

1. **登录**：学号 + 密码（或直接粘贴已有 token，约 12h 有效）。
2. **选课程**，选**任务类型**：
   - 挂机计时：每题时长区间（默认 5–10 分钟）+ 错误注入区间（默认 1–3 次，0 = 不注入）；
   - 自动刷题：可选**仅探测**（只跑空桩拿答案表，不交 round-2，不改 pass——首次使用建议先探测）。
3. **开始**：逐题处理；**停止**：当前题处理完即收尾。
4. **刷完自动下线**：任务一结束（跑完、手动停止、出错、被踢）即清除本地会话与 token；
   出错中止时先下线让位，默认 3 小时后自动重登续跑，密码被拒则放弃计划（防锁号）。

## 自动刷题语义（solve）

- 只处理**未通过**且 `questionType < 2` 的题（实验/课设走另一套 Lab 接口，本科生 401，跳过）。
- 上游判题有抖动：gdb 驱动判题，同一份代码两次判的 err 数都不同，甚至一次判败一次判过
  （DC07PE15 实测）。题解库直交判败不记失败，原样重交最多 4 次，抖回 `passed=true` 即落账。
- 流程：取题目档案（kind/language/QF）→ 取模板 → `code/release` 清编译目录 →
  空桩 compile + runGroup 收 oracle → 解析 (输入, 正确结果) 对 → 生成查表代码 →
  release → compile + runGroup 验证 → `passed=true` 记通过 → **存档原样还原**（读回核对）。
- 题型判别看「有没有空桩函数」而非 main：函数补全题的模板 Dx.cpp 本来就自带 main
  （analysis/08），学生代码只能是函数，交带 main 的整程代码会 `multiple definition of main`；
  无空桩视为整程题，整体替换为独立查表程序。
- 查表匹配把**整块 stdin**（constructor 在 main 前截留）与每组输入做**空白归一化**后字面比对，
  命中打印该组正确输出并 `exit(0)`；未命中走原函数体（必然判不过，无副作用）。
  判题结果以 runGroup `passed=true` 为准，没过就是没过，不会落假账。
- 安全边界：compile/runGroup 会顺带把提交代码覆盖进学生存档（analysis/09 实测），
  所以任何提交前快照、结束后回写并读回核对，失败重试 3 次大声告警；round-2 交卷前
  release 防粘滞上一题模板；解析不出 oracle（格式变化）时原文进日志、该题记失败跳过。
- 通过的题服务端不再计时（analysis/10）——「先挂时长再刷题」还是「直接刷」自行权衡。

## 挂机计时语义（idle）

- 目标区间 `[下限, 上限]` 是每题 accumTime 的目标带（分钟）：现累计 ≥ 下限 → 跳过；
  否则挂到带内随机目标点，挂完复核 catalog 确认真涨了。
- 错误注入在挂完之后：`[下限, 上限]` 次（随机抽）编译错（自己的代码砍一刀）或
  运行错（跑自己的未通过代码）；**绝不注入运行正确**（会判过改 pass）。
- 已通过题一律跳过——服务端对 pass=true 的题不计时，挂了也是白挂。
- 换题间隙随机 8–23s 仿人翻题；HTTP 请求每题仅 2 次（刷前确认 + 挂后复核）。

## 计时原理（为什么是 WebSocket）

accumTime 唯一来源是 exam WS 的 **401 计时消息对**（HTTP 做题接口一律不计时）：

```
wss://anyview.gdut.edu.cn/api/exam-service/websocket/{token}
{type:401, content:<eID>}  开始给该题计时
{type:401, content:null}   停止
{type:117}                 心跳, 每 40s
{type:206}                 连上先问考试安排（前端行为）
type:119                   token 失效/单点登录被踢 → 本轮中止, 重新登录再开一轮
statusType:403             停留过长 → 断开重连后重发 401 续计时
```

计时器**单活**：服务端同一时刻只记一题，所以逐题串行挂。挂机只动计时器，不碰代码存档、
不触发判题、不改 pass，账号侧无副作用。

## 已知约束

- **会话生命周期**：账号只在配置/刷机期间被持有，任务结束即自动下线。重启时若有未完成
  任务：token 仍有效则直接续跑（复用自己的会话，不踢人）；失效则让位重登。平时重启保持
  离线，不会顶着你的网页会话互踢。
- **用户优先的让位重登**：任务因 token 失效/被踢/网络问题出错中止时，先下线让位，默认
  3 小时（`-relogin-wait` 可调）后自动重登续跑剩余题目；重登撞上网络/服务端问题 30 分钟
  后重试，密码被拒则放弃计划（防连续错锁号）。期间手动登录或开任务即视为接管。
- token 有效期约 12h，长跑中途 119 被踢无需人工干预——下线让位后到点自动续跑。
- 走默认云 WAF 无需额外配置；若 `/etc/hosts` 把域名指到源站直连，登录时必须填
  **X-Forwarded-For**（你的公网出口 IP，登录后不可变），否则网关一律 405/403。
- 密码连续输错有锁号风险（约 3 次），后端不做重试。
- 服务只绑本机 `127.0.0.1`，API 本身无鉴权，公开访问须经反代；会话按 cookie 隔离，
  但任何能访问到服务的人都能注册自己的会话登录刷课——不想开放就在反代层加访问控制。
- 前端 `web-src/`（Vite + Vue 3 + Element Plus）构建产物落 `web/dist/` 并随二进制内嵌
  （SPA fallback）；`?shot=1&stage=…` 可在无账号环境下用内置夹具截图验收 UI。

## 结构

```
main.go                  HTTP 路由 + SPA 内嵌托管
session.go               多账号会话: cookie 隔离/按会话持久化/让位重登计时
internal/anyview/
  client.go              登录(RSA)/课程列表(多版本归一化)/catalog/compile/runGroup
                         /存档快照回写/取模板/release
  limiter.go             全局上游限速 (60s 滑动窗口, 所有账号共享)
  timer.go               exam WS 计时器 (401/117/206/119/403, 20s 分片, 断线重连续挂)
  brusher.go             idle 编排: 区间随机目标点/跳过达标/错误注入/复核到账/日志环
  solver.go              solve 编排: oracle 解析/查表代码生成/两轮判题/存档还原
  solver_test.go         解析器与 codegen 单测 (gcc 实编译+实运行行为验证)
web-src/                 Vue 3 + Element Plus 前端源码 (Vite, teal MD3 主题)
web/dist/                前端构建产物 (内嵌进二进制)
```
